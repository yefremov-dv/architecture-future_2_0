# Роадмапы для технологий со статусами "Вывод из эксплуатации" и "Опытно-промышленная эксплуатация"
*Задания 3.2 и 3.3 (описание этапов внутри проектов) выполнялось только для тех элементов ИТ-ландшафта, которые либо выводятся из экслуатации, либо внедряются. Если внедрение новой технологии также подразумевает переход со старой, то это разбивалось на два отдельных проекта. Подход реализован с целью реального отражения трудозатрат требуемых ресурсов. Пример: внедрение PostgreSQL на уровне всей организации (проект №8) и проект миграции с MS SQL 2008 (№1), аналогично для BI решения*
Ниже приведена текстовая часть задания. Дополнительно приложена схема, где отражен roadmap и зависимости проектов.

## 1. **DWH (Центральный узел сбора данных на MS SQL Server 2008)**
**Статус:** Вывод из эксплуатации

### Проект: Миграция с MS SQL Server 2008 на PostgreSQL
**Этап 1:** Анализ текущего состояния инфраструктуры и требований бизнеса  
*Описание:* Необходимо оценить состояние используемого программного обеспечения и инфраструктуры, определить требования бизнеса к новым технологиям и возможные ограничения. Это позволит выбрать оптимальное решение для миграции.  
- **Ответственная команда:** Отдел архитектуры данных  
- **Ресурсы:** ИТ-специалисты, аналитики данных, инженеры базы данных  

**Этап 2:** Разработка плана миграции и тестирование прототипа системы  
*Описание:* Подготовить подробный план миграции, включая стратегию переноса данных, процедур и настроек. Протестировать новый вариант системы на тестовом стенде, чтобы убедиться в работоспособности и отсутствии потерь данных.  
- **Ответственная команда:** Команда разработчиков и тестировщиков  
- **Ресурсы:** Инженеры DevOps, разработчики баз данных, серверное оборудование  

**Этап 3:** Реализация миграционного сценария и запуск новой инфраструктуры  
*Описание:* Осуществить запланированную миграцию, запустить новую систему и обеспечить поддержку процесса. Проверить стабильность и работоспособность всей инфраструктуры после завершения миграции.  
- **Ответственная команда:** Операционная группа IT  
- **Ресурсы:** Серверы PostgreSQL, средства мониторинга производительности  

**Результат:** Полностью обновленная система управления данными на платформе PostgreSQL.

## 2. **Power BI (Система визуализации и анализа данных компании)**
**Статус:** Вывод из эксплуатации

### Проект: Замещение Power BI на Yandex DataLens
**Этап 1:** Оценка текущих отчетов и панелей инструментов  
*Описание:* Проанализировать используемые отчёты и панели инструментов в Power BI, выявить наиболее востребованные и важные элементы. Определить совместимость имеющихся данных и процессов с новой системой.  
- **Ответственная команда:** Бизнес-аналитики и специалисты отдела отчетности  
- **Ресурсы:** Специалисты по обработке данных, сотрудники службы поддержки пользователей  

**Этап 2:** Тестирование и настройка Yandex DataLens  
*Описание:* Провести серию тестов для проверки функциональных возможностей Yandex DataLens, настроить интерфейс и взаимодействие с существующими системами, удостоверившись в полной готовности к использованию.  
- **Ответственная команда:** Разработчики BI-отделов  
- **Ресурсы:** Лицензии на использование платформы Yandex DataLens, обучение персонала  

**Этап 3:** Переход всех существующих отчетов и внедрение новых возможностей  
*Описание:* Переносить все ранее созданные отчёты и создавать новые, используя преимущества новой платформы. Организовать процесс адаптации пользователей и поддержать полную функциональность системы.  
- **Ответственная команда:** Пользователи Power BI и администраторы системы  
- **Ресурсы:** Дополнительные лицензии на расширенные сервисы и доработки  

**Результат:** Полноценная интеграция Yandex DataLens в корпоративную инфраструктуру.
